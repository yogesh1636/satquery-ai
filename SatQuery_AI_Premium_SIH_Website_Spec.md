# SatQuery AI — Premium AI Product Website Specification

## Goal

Transform the existing SatQuery AI project into a premium, futuristic, AI-first product website inspired by the **quality, storytelling, motion, and polish of modern next-generation AI product sites**.

This should be **inspired, not copied**. Create an original SatQuery AI identity.

The website should feel like a serious deep-tech / Earth-observation product suitable for **Smart India Hackathon (SIH)** presentation.

---

**Product:** SatQuery AI

**Tagline:** `Ask. Analyze. Explore.`

An AI-powered vision-language assistant for multimodal remote-sensing image analysis through natural-language queries.

- Satellite imagery

# 24. Motion Design

- Section fade-ins
- Text reveals
- Technical line drawing
- Data nodes
- Card hover
- Query loading animation
- Before/after slider
- Smooth scrolling
- Limited parallax

```css

```

Avoid:

- Rapid flashing
- Excessive particles
- Heavy cursor effects
- Gaming-style animations
- Constant motion

Support reduced-motion preferences.
